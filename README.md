# What Would You Say? — Kevin's Blue Website Starter

This version keeps Kevin's three existing scenarios but divides the site into three real pages with one shared CSS file.

## File map

- `index.html` — introduction and the idea.
- `interactive.html` — choice activity. The buttons are generated by JavaScript.
- `action.html` — advocacy, real-world evidence, and service-learning plan.
- `style.css` — ALL colors are defined once at the top under `:root`. No scattered HEX values or old `--purple` / `--lilac` variables.
- `scenarios.js` — the `scenarios` array and its display logic. Add scenarios to the array; don't duplicate buttons in the HTML.

## Editing the colors

Change the `:root` tokens at the very beginning of `style.css`. The blue shades are `--blue-950` through `--blue-50`; `--accent` colors the decorative underline, logo punctuation, and squiggle. `--mint-100` and `--amber-100` distinguish supportive and reconsider-this feedback. They are meaningful status colors, not competing brand colors.

## Adding a scenario

Open `scenarios.js` and add another `{ intro: ..., friendMessage: ..., choices: [...] }` object **inside** the `scenarios` array, separated by a comma. Each choice needs `text`, `heading`, `explanation`, and `tone` (`positive` or `reflect`). The on-page progress indicator adjusts itself.

## Running it

Unzip into one folder and open `index.html` in Chrome. All files must stay together, since pages link to `style.css` and `scenarios.js` by relative paths. For a local development server in VS Code, use Live Server, or from a terminal run `python -m http.server 8000` in this folder.

## Google Sites

Google Sites DOES NOT act as a traditional static-file host where you can upload a folder of related HTML/CSS/JS files and keep relative URLs. Do not paste only `index.html` into an Embed code field; then the sibling stylesheet and JavaScript files will not resolve.

Instead, publish the folder on a static hosting service such as GitHub Pages, then in Google Sites use Insert → Embed → By URL (or Pages → Full-page embed) to point to the published page. Check whether the hosting service permits iframe embedding. Or link to the hosted pages from buttons in Google Sites. If relying on Google Sites alone, a standalone embedded snippet must include its CSS in a `<style>` element and JavaScript in a `<script>` element.
